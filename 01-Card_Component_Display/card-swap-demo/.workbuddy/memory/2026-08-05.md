# 2026-08-05

## 卡片轮播组件：项目改为单文件 HTML

- 用户观点：组件素材积累场景不需要完整工程，单文件 HTML 更轻便。同意并执行了转换。
- 原 `card-swap-demo/` 为 Vite + React + TS + GSAP 工程（node_modules 73MB，源码仅 5 个文件）。
- 产出 `card-swap.html`（80KB）：原生 JS 版 `createCardSwap(container, options)` 组件 + 演示页，GSAP 从 node_modules 内联进文件，离线双击可用。
- 组件参数：width/height/cardDistance/verticalDistance/delay/pauseOnHover/skewAmount/easing('elastic'|'linear')/onCardClick，返回 destroy()。
- 动画逻辑与原 React 版一致（gsap timeline：drop → promote → return）。
- 原 card-swap-demo 工程保留未删，用户可自行决定是否清理。
