02 · 滚动变色 · 盒子区块

sand-100 圆角盒子

Lattice 的内容区块不是通栏色带，而是 3.2rem 大圆角的"卡片盒子"（.box），背景 sand-100(#f7f6f2)，悬浮在页面渐变底上。滚动进入时产生背景色切换的感觉。

03 · 滚动变色 · 深色锚点

purple-600 深紫盒子

整页唯一的深色区块 purple-600(#624ee5)，在连续的浅色粉彩中形成一个强对比锚点，是"背景色变换"节奏感的关键——浅 → 浅 → 深 → 浅。

04 · 动态渐变 · 无限循环

彩虹流动渐变（oklch 插值）

原站用在主 CTA 按钮上：oklch 色彩空间做 5 段往返渐变（荧光绿 #d0ff64 → 青 #52e5ff → 粉 #fbe3ff → 青 → 绿），背景放大到 300%，8 秒线性移动 background-position 到 150%，实现无缝循环流动。


8s · linear · infinite · background-position 0% → 150%

关键点：linear-gradient(in oklch …) 让中间过渡色不发灰；首尾颜色相同（A→B→C→B→A）配合 300% 宽度实现无缝循环。

05 · 渐变 token 体系

7 色粉彩渐变（gradient-*-100）

Lattice 的全站渐变不是随意拉的，而是一套设计 token：lime / yellow / pink / purple / blue / teal / green × 50 / 100 两档浓度。每个都是 225deg 双层结构——上层 40% 透明彩色斜向罩染，下层实色 pastel 托底。
