# 配色网站推荐

收集三个好用的配色网站，覆盖渐变、色卡挑选与自动生成三大场景。

## 1. UI Gradients

- 网址：<https://uigradients.com>
- 特色：几百款现成的「双色渐变」，按名字搜索（如 Sunset、Dusk、Rainbow）。
- 用法：选好渐变后，直接把页面里生成的 CSS `linear-gradient` 代码复制走，或用它的 `.open` 工具抓色值。

## 2. LOL Colors

- 网址：<https://www.lolcolors.com>
- 特色：人工精选的「4 色搭配」色卡库，每个色卡都是扁平、多色配好的组合，适合快速找整体品牌色或 UI 色板。
- 用法：点开喜欢的色卡，用昵称搜索（如 Kids、Sunset、Midnight），逐色复制 hex 值。

## 3. Color Space

- 网址：<https://mycolor.space>
- 特色：输入一个主色，自动生成同色系/撞色系调色板，还支持渐变与三色渐变生成。
- 用法：填入任意 hex 值点 Generate，从候选配色里挑一套，可直接导出 CSS、Tailwind 或图片。

## 小结

| 网站        | 主用途             | 适合场景                 |
| ----------- | ------------------ | ------------------------ |
| UI Gradients | 渐变              | 背景、按钮、封面渐变     |
| LOL Colors  | 精选色卡          | 品牌色、UI 色板          |
| Color Space | 按主色自动生成      | 定制主题、完整配色方案   |
