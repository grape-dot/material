## 分项规格（详细版）

### 1. 风格定位
| 项 | 值 |
|---|---|
| 风格名称 | Kimi Archive 档案美学 |
| 视觉参考 | 现代艺术档案馆 / 瑞士编辑设计 / Apple 产品视觉 / 高级杂志摄影 / 创意工作室静物摄影 |
| 场景意象 | 未来创意机构、设计工作室、博物馆展览中的研究档案桌 |
| 气质关键词 | 高级、克制、安静、理性、收藏感 |

### 2. 构图
- 俯视角平面摄影，单张大号柔光灯箱桌面
- 根据画幅比例自动调整布局（5:2 / 16:9 / 4:5 / 3:4 / 9:16 / 1:1）
- 大留白，视觉呼吸感，标题区保持干净，不填满画面

### 3. 主题视觉转换（禁止模板化）
- 自动提取主题核心概念，转化为真实物件与视觉隐喻，不直接堆放文字
- 按主题重新设计：主视觉物件、辅助物件、摆放位置、数量、层次、空间关系
- 禁止每次使用相同物品组合

### 4. 物件规范
- 少量、高关联、每个物件服务主题
- 可选类型：专业工具 / 材料样本 / 模型 / 仪器 / 艺术品 / 书籍 / 地图 / 手稿 / 产品原型 / 自然元素 / 收藏品
- 禁止：大量纸张、堆满文件、无意义装饰
- 目标：像真实创作者或研究者的工作台

### 5. 摄影质感
- 真实静物摄影，顶视角，高级产品摄影
- 柔光，自然阴影，电影级调色
- 真实材质：金属 / 玻璃 / 木材 / 陶瓷 / 纸张 / 织物 / 颜料

### 6. 颜色
- 主色：淡灰绿色 / 浅薄荷绿（低饱和）
- 辅助：米白、暖白、浅灰、自然材质色、少量深黑
- 禁止：霓虹科技风、赛博朋克、廉价未来感、复杂 UI 界面、过度发光

### 7. 文字
- 标题清晰锐利、高级编辑字体、视觉中心突出
- 禁止模糊文字、乱码、大量小字
- 辅助区域保持空白或简单符号

### 8. 最终效果
- 顶级设计杂志封面
- 重要项目的视觉档案
- 创意总监收藏的研究桌
- 长期系列品牌感
