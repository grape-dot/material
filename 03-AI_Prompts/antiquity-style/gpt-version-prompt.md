# MASTER STYLE PROMPT  
## 中国古典水墨卷轴 × 现代杂志编辑设计

### 1. 核心风格提示词

中国古典水墨卷轴与现代高端杂志编辑设计融合的东方视觉风格。画面以浅米白、暖象牙色、淡旧纸色的羊皮纸或宣纸肌理为基础，呈现自然纤维、轻微斑驳、柔和磨损、淡淡水渍与岁月包浆，但整体保持干净、克制、精致，不做过度仿古或脏旧处理。

视觉语言融合宋代山水画、传统工笔花鸟、古籍装帧、卷轴展开结构、东方留白美学，以及瑞士国际主义版式、现代艺术杂志、博物馆展览图录和高端文化刊物的编辑设计。传统艺术元素以现代平面设计方式重新组织，形成古典意境与当代秩序并存的视觉系统。

整体构图采用清晰的模块化网格、非对称平衡、大面积留白、纵向分栏与横向信息区块。版面具有稳定的视觉轴线，局部使用深色竖向色块、窄栏、编号区域、图像窗口和细线分隔，使画面具有杂志目录页、文化专题页、艺术展览册或品牌视觉手册的高级感。

画面中的传统元素可包括：层叠远山、云雾、松树、亭台楼阁、江面孤舟、飞鸟、竹叶、花枝、印章、卷轴边缘、古典纹样、淡金线描与水墨晕染。所有元素均应作为氛围与视觉语言存在，不照搬任何参考图中的具体文字、标题、段落或版面内容。

### 2. 色彩系统

采用低饱和、温润、雅致的东方传统配色：

- **浅羊皮纸色 / 暖象牙色**：作为主背景，占据大部分画面。
- **朱红**：用于少量标题、编号、印章或重点视觉符号。
- **鎏金 / 哑光金**：用于细线、纹样、边框、装饰性笔触或小面积强调。
- **玉石绿 / 深黛绿**：用于主视觉色块、分栏背景、竹叶或山水局部。
- **云蓝 / 灰蓝**：用于水墨山体、云雾、远景和辅助信息。
- **墨黑 / 深褐**：用于正文、线条、山石和高对比细节。

配色比例建议遵循：

- 60%–70% 浅色纸张背景
- 20%–30% 玉石绿、云蓝、水墨灰
- 5%–10% 朱红与鎏金点缀

整体避免高饱和、荧光色、纯黑大面积铺陈和强烈数码渐变。

### 3. 材质与画面质感

纸张具有真实但克制的物理质感：

- 宣纸纤维
- 羊皮纸颗粒
- 轻微旧化边缘
- 柔和水渍
- 淡淡折痕
- 印刷油墨渗透
- 水墨自然晕染
- 哑光烫金或金粉颗粒
- 轻微套印误差
- 古籍印刷与现代精品印刷结合

材质应细腻、真实、可触摸，避免粗糙噪点、重度破损、过强污渍、烧焦边缘或廉价复古滤镜。

### 4. 构图与版式规范

画面采用现代杂志编辑结构，而非单纯传统绘画：

- 使用严谨的网格系统组织内容。
- 保留充足留白，避免所有区域被填满。
- 通过纵向色块、窄栏、章节编号、细线和图像窗口建立层级。
- 主要视觉集中于一至两个区域，其余区域保持安静。
- 传统山水与花鸟元素可跨越不同版块，但不能破坏网格秩序。
- 画面左右或上下形成主次关系，避免完全对称。
- 细线分隔应轻、细、克制，不使用厚重边框。
- 数字编号、章节标记、印章和小型装饰文字仅作为视觉符号，不承担具体内容复刻。
- 视觉节奏应有疏有密，形成“留白—重点—留白”的呼吸感。

### 5. 传统艺术元素的表现方式

传统山水采用淡墨、青绿设色与浅彩晕染结合：

- 山体层次清晰，远山更淡、更虚。
- 云雾与水面保持大面积空白。
- 建筑体量小而精致，作为山水中的视觉锚点。
- 花鸟使用工笔与写意结合，细节精致但不过分写实。
- 竹叶、花枝、松树和飞鸟以少量点缀出现。
- 金色线描可用于云纹、波纹、山脉轮廓或边缘装饰。
- 印章应小巧、自然，避免过多堆叠。

传统元素不应呈现旅游海报、古装影视海报或游戏概念图风格，而应更接近艺术图录、文化刊物、博物馆出版物和高级品牌视觉。

### 6. 光线与氛围

使用柔和、均匀、漫反射的自然光或棚拍柔光。画面整体低对比、低饱和、安静、温润。纸张边缘、卷轴结构和局部压纹可有轻微阴影，以增强真实层次，但不得出现强烈硬阴影、戏剧化聚光灯或过度电影化光效。

氛围关键词：

东方、静谧、典雅、理性、克制、温润、诗意、古今融合、收藏感、文化感、博物馆级、编辑设计感、精品出版物质感。

### 7. 字体与文字区域规范

本提示词仅定义视觉风格，不复制参考图片中的任何文字内容。

若生成画面需要文字区域：

- 使用抽象占位文字、不可读的排版块或极少量通用标题。
- 中文主标题可采用现代化书法字体、宋体或高对比衬线字体。
- 英文辅助文字可采用细衬线体或瑞士无衬线体。
- 字号层级清晰，字距宽松，行距舒展。
- 避免大段可读中文，以减少乱码和错误字形。
- 最终正式文字建议在设计软件中后期排版。

### 8. 高质量生成约束

要求画面具备：

- 清晰的编辑设计逻辑
- 完整的视觉层级
- 精准的留白控制
- 真实纸张与水墨材质
- 细腻的传统绘画笔触
- 稳定的色彩体系
- 高级文化刊物质感
- 博物馆展览图录级审美
- 细节丰富但不过载
- 高分辨率
- 边缘清晰
- 无明显透视错误
- 无不合理重复元素
- 无廉价模板感
- 无过度装饰

### 9. 负面提示词

避免：

现代霓虹色、赛博朋克、3D塑料质感、金属科幻界面、强烈玻璃拟态、炫光、荧光渐变、过度饱和、纯黑大背景、卡通、动漫、儿童插画、廉价国潮、电商海报、春节广告、旅游宣传页、游戏UI、古装影视海报、重度做旧、烧焦纸张、脏污、霉斑、破损、厚重边框、复杂纹样堆叠、元素拥挤、信息爆炸、缺少留白、强透视、摄影级真实山景、欧式装饰、阿拉伯纹样、日式浮世绘、韩式插画、低清晰度、模糊、噪点、乱码、错别字、重复文字、变形印章、比例错误、山水结构混乱。

### 10. 可直接使用的整合版提示词

中国古典水墨卷轴与现代高端杂志编辑设计融合的东方视觉风格，浅米白与暖象牙色宣纸、羊皮纸背景，细腻自然纤维、轻微旧化、水墨渗透与柔和包浆质感。融合宋代山水、青绿山水、工笔花鸟、古籍装帧、卷轴结构、东方留白美学，以及瑞士网格、现代艺术杂志、博物馆展览图录和精品文化刊物版式。采用模块化网格、非对称平衡、纵向分栏、窄栏色块、章节编号、细线分隔和大面积留白，视觉层级清晰，节奏疏密有致。画面包含层叠远山、云雾、松树、亭台、江面孤舟、飞鸟、竹叶、花枝、印章、淡金云纹和水墨晕染，但不复制任何具体文字或原图内容。主色为浅羊皮纸色，辅以朱红、哑光金、玉石绿、云蓝、水墨灰和墨黑，低饱和、温润、克制。纸张、墨迹、金线与印刷细节真实细腻，柔和漫反射光，低对比，安静、理性、诗意、具有收藏感。整体呈现高级文化杂志、艺术图录、品牌视觉手册和博物馆出版物质感，高分辨率，构图完整，留白充分，细节精致，无廉价模板感，无过度装饰。

### 12. 推荐使用方式

```text
不生成任何可读文字，保留干净标题区和正文排版区，所有正式文字后期添加。
```

生成带杂志结构的概念图时，在提示词末尾增加：

```text
允许少量抽象编号、章节标记和不可读占位排版，但不得生成完整中文段落。
```
